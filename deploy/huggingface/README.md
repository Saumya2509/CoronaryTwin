# CoronaryTwin API

Backend for [CoronaryTwin](https://github.com/Saumya2509/CoronaryTwin): calibrated coronary risk estimates per artery,
conformal uncertainty, SHAP explanations, guideline scores and report reading.

- Health check: `/health`
- Interactive API docs: `/docs`

For decision support and educational purposes only. Not a substitute for formal diagnostic imaging or clinical judgment.
